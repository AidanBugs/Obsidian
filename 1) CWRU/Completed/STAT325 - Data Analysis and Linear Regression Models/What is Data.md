# Data
Ideally we get data for the entire population to get a very accurate sense of the true data set. However collecting all of this data is not always feasible for a wide variety of reasons. As such we resort to sampling the population.

## Observational Data vs Expiremental Data
Observational:

- Data is observed and the researcher does not intervene to collect data

Expiremental:

- Research imposes constraints or requirements and then collects data
- Controlled Expirement:
    - Independent variable is assigned
- Random Expirement:
    - Independent variable is random

## Data Vocabulary

Units
- Rows of table

Variables
- Columns of the table

Quantitative Data
- Well defined numerical sscale 

Qualitative Data
- Categorical Data

Response (dependent variable)
- Variable of "interest" what are we looking at changing (output)

Predictor (Independent variable)
- Variable we change / observe change and the effect on Resonse variable (input)
