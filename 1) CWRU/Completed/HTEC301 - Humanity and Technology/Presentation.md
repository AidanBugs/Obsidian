## What is huggingface?
Open source (all stuff is free, u can use it, edit it, see source code etc) community for people sharing AI models, data sets, tools etc. Since it is open source and people share their work, we can see how people are using and modifying existing open source models and posting these now fine tuned models. 

## What are model benchmarks?
Model benchmarks are created to have a numerical metric to measure an LLM's performance. Benchmarks take a wide variety of input and output formats. In other words, the question / data given to the LLM could be text, visual, file formats etc and expect the model to pick from multiple choice, output text in a format etc. Of course benchmarks have a wide variety of scoring mechanisms specific to the benchmark but always output some score that stems from the model's performance on the benchmark.
