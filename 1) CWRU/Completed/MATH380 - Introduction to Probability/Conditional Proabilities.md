# Conditional Probabilities
This refers to the probability an event occurs given another event has already occured. 

$P(A|B) = \frac{P(A\cap B)}{P(B)}$


# Bayes Theorem
$P(A|B)=\frac{P(B|A)\times P(A)}{P(B)}$, in english: The probability A is true knowing that B is true is equal to the probability that B is true knowing A is true times the probability of A divided by the probability of B.

We know this is true because $P(B|A) = \frac{P(A\cap B)}{P(A)}$ so the above simplifies to $P(A|B)=\frac{P(A\cap B)}{P(B)}$ which is how we defined conditional probability above
