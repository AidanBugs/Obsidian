# Statistical Modeling 
A statistical model is a mathematical relationship between random variable and fixed variables. However unlike mathematical models these models are not deterministic because they typically include some error/noise $\epsilon$.

## Why do we need an error term?
There are a variety of reasons that can cause errors thus an error term is necessary. These reasons could be:

- Measurement Errors
- Modeling Errors
- Sampling Erros

## Link Functions
Link function $g$ is used to create better models. $g$ could be $\log$, identity etc. The only linear part is the $\Beta$ part, ie $m = \Beta_1 x_1 + ....$
