# 8.15
Area of trapezoid $A=\frac{top + bottom}{2}=\frac32$

$f_{X,Y}(x,y)=\frac 23, (x,y)\in D, 0$ otherwise.

We have the bounds $0\leq x \leq 1, 0 \leq y \leq 1$ and $1\leq x \leq 2, 0\leq y \leq 2-x$

$Cov(X,Y) = E(XY)-E(X)E(Y)$

> $E(XY) = \int_0^1\int_0^1 \frac23 xy dx dy + \int_1^2 \int_0^{2-x} \frac23 xy dy dx$

> $E(XY) = \int_0^1 \frac13 y dy + \int_1^2  \frac13 x(2-x)^2 dx$

> $E(XY) = \int_0^1 \frac13 y dy + \int_1^2  \frac13 (4x -4x^2 + x^3) dx$

> $E(XY) = \frac 16 + \frac13 (2x^2 -\frac43x^3 + \frac 14x^4)|_1^2$

> $E(XY) = \frac 16 + \frac13 (8 -\frac{32}3 + 4 - (2-\frac43 + \frac14))$

> $E(XY) = \frac 16 + \frac13 (10 -\frac{28}3 - \frac14)$

> $E(XY) = \frac 16 + \frac13 (\frac5{12})$

> $E(XY) = \frac {11}{36}$

> $E(X) = \int_0^1\int_0^1 \frac23 x dy dx + \int_1^2 \int_0^{2-x} \frac23 x dy dx$

> $E(X) = \int_0^1 \frac23 x dx + \int_1^2  \frac23 2x-x^2 dx$

> $E(X) = \frac 13 + \frac23 (x^2-\frac13 x^3)|_1^2$

> $E(X) = \frac 13 + \frac23 (4-\frac83 - (\frac23))$

> $E(X) = \frac 13 + \frac23 (4-\frac{10}3)$

> $E(X) = \frac 13 + \frac49$

> $E(X) = \frac79$

> $E(Y) = \int_0^1\int_0^1 \frac23 y dx dy + \int_1^2 \int_0^{2-x} \frac23 y dy dx$

> $E(Y) = \frac 13 + \int_1^2 \frac13 (4-4x+x^2) dx$

> $E(Y) = \frac 13 + \frac13 (4x-2x^2+\frac13 x^3)|_1^2$

> $E(Y) = \frac 13 + \frac13 (\frac 83 - (2+\frac 13))$

> $E(Y) = \frac 13 + \frac19$

> $E(Y) = \frac{4}9$

$\rightarrow Cov(X,Y)= \frac{11}{36} - \frac79\frac49 = \frac{11}{36} -\frac{28}{81} = -\frac{13}{324}$

Based on the desecription of this expirement the Covariance should be negative because as $X$ increases, $Y$ tends to deacrease (specifically for $x>1$).

# 8.26
## a
$P(X=G)=\frac 49$

$P(X=Y)=\frac 39$

$P(G \text{ then } Y)=\frac49\frac39=\frac{12}{81}=\frac4{27}$

With $n$ draws, there are $n-1$ consecutive pairs. $E(X_n)=(n-1)*P(G \text{ then } Y)=(n-1)\frac4{27}$

## b
We can model this as a geometric distribution.

Let $NW$ denote the number of draws before we see a white.

$P(NW=k)=(1-\frac29)^{k-1}\frac29$

$E(NW)=\frac{1-p}{p}=\frac72$ for $k$ failures.

Then the probability a non white is green is $\frac47$

Therefore $E(Y)=E(NW)\frac47 = 2$ 

An intuitive approach is there are twice as many greens as there are white, meaning that for each white there are 2 greens. 

# 8.37 
## a
Let $T_i\geq 1$ denote that there is at least $1$ copy of the $i$th toy.

$P(T_i\geq 1)=1-P(T_i=0)=1-(\frac9{10}\frac89)^4=1-\frac45^4=1-\frac{256}{625}=\frac{369}{625}$

Here $P(T_i\geq 1) = P(J_i=1) = E(J_i)$ where $J_i$ is the indicator variable for the $i$th toy.

$E(X)=\sum_{i=1}^{10}E(J_i)=\frac{3690}{625}=\frac{738}{125}$

## b
$Var(X)=\sum Var(J_i) + \sum_{i=1}^{10}\sum_{k\neq i} Cov(J_i,J_k)$

$\rightarrow Var(X) = 10 Var(J_1) +10*9 Cov(J_1,J_2)$

> Given in the textbook, $Var(J_1)=p(1-p)=\frac{256}{625}\frac{369}{625}=\frac{94464}{390625}$

$\rightarrow Var(X) = 10(\frac{94464}{390625}) +10*9 Cov(J_1,J_2)$

> $Cov(J_1,J_2)=E(J_1J_2)-E(J_1)E(J_2)$

>> $E(J_1J_2)=1-(P(J_1=0)+P(J_2=0)-P(J_1=0\land P(J_2=0))$

>> $E(J_1J_2)=1-(\frac{256}{625}+\frac{256}{625}-(\frac{8}{10}\frac{7}{9})^4)$

>> $E(J_1J_2)=1-(\frac{512}{625}-(\frac{28}{45})^4)$

>> $E(J_1J_2)=\frac{1356049}{4100625}$

> $Cov(J_1,J_2)=\frac{1356049}{4100625}-\frac{369}{625}^2$

> $Cov(J_1,J_2)=\frac{1356049}{4100625}-\frac{136161}{390625}$

> $Cov(J_1,J_2)=\frac{-45821696}{2562890625}$

$\rightarrow Var(X) = \frac{944640}{390625} +90(\frac{-45821696}{2562890625})$

$\rightarrow Var(X) = \frac{944640}{390625} +\frac{-91643392}{56953125}$

$\rightarrow Var(X) = \frac{9217024}{11390625}\approx 0.8091763182441701$

# 9.21
$E(X_i)=E(Y_i)=2$

$Var(X_i)=2, Var(Y_i)=3$

$P(\sum_{i=1}^{500} X_i > \sum_{i=1}^{500} Y_i +50)$

Let $S_n=\sum X_i - \sum Y_i$

$P(\sum_{i=1}^{500} X_i > \sum_{i=1}^{500} Y_i +50)=P(S>50)$

$\rightarrow P(\frac S{\sigma \sqrt n}>\frac{50}{\sigma\sqrt n})$

> $n=500,\sigma^2 = Var(X_i)+Var(Y_i)=5$

> $\sigma \sqrt n = 50$

$\rightarrow P(\frac S{50}>50)=1-\Phi(1)=1-0.8413=0.1587$
