# 1.1
$(i,j) \in\Omega$, where $i,j \in \{1,2,3,4,5,6\}$.

Let $A=\{\text{Second Roll is Higher than the first}\}$ 

| First Roll | P(A) |
| --- | --- |
| 1 | 5/6 |
| 2 | 4/6 |
| 3 | 3/6 |
| 4 | 2/6 |
| 5 | 1/6 |
| 6 | 0/6 |

Thus $|A| = 5 + 4 + 3 + 2 + 1 = 15$ 

$|\Omega|=6*6=36$

$P(A)=\frac{|A|}{|\Omega|}=\frac{15}{36}=\frac{5}{12}$
