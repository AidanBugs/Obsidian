# Definitions
$\Omega= $ {all possible outcomues of some experiment / random experience}

$\mathbf{F} =$ powerset

$|\Omega| = n^k$ if sampling with replacement

$|\Omega|=nPk = \frac{n!}{n-k!}$ if order matters

$|\Omega|=nCk = \binom nk = \frac{n!}{k!(n-k)!}$ if order does not matter

$P(A)=\frac{|A|}{|\Omega|}$

$P(A)=1-P(A^c)$
