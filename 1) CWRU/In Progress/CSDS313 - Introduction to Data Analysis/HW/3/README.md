# Running this project
This project uses Quarto to render the report and execute code. For this project, Quarto is operating as a fancy form of jupyter notebooks with proper PDF formatting. All code can be found in the "HW3.qmd" file. Blocks of code are hidden to ensure the report is nicely formatted, howevere some code outputs are displayed (ie graphs). If a grader wishes to render the pdf on their own laptop they may download quarto at quarto.org and configure an installation. Alternatively, copy the contents of the HW3.qmd file into a .py file and remove any content outside of the python code blocks.
